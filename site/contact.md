# Contact SkyQuery

SkyQuery is an independent open-source project, so every channel below is public and handled by the maintainer, Karthik Subramanian. Pick the one that fits what you need. The project is based in Berkeley, California.

## Bugs and feature requests

Open an issue on [GitHub issues](https://github.com/KarthikSubramanian07/skyquery/issues). Include the SkyQuery version (`skyquery version`), your operating system, the exact command or MCP tool call, and the output you saw. If the problem only happens in live mode, say which upstream service was involved (for example SIMBAD or JPL Horizons), because outages at public services are a common cause.

## Questions and ideas

Start a thread in [GitHub discussions](https://github.com/KarthikSubramanian07/skyquery/discussions). This is the right place for "how do I…" questions, integration help with a specific MCP client, or proposals for new data sources and tools.

## Security reports

Please do not open a public issue for security-sensitive reports. Follow the private reporting process in the [security policy](https://github.com/KarthikSubramanian07/skyquery/blob/main/SECURITY.md), which lists the maintainer's email address. You should receive an acknowledgment within a few days.

## Supporting the project

SkyQuery is free and always will be. If it saves you time, you can [buy the maintainer a coffee](https://buymeacoffee.com/winnerkarthik) or star the repository on GitHub.

## Response times

This is a volunteer project, so replies usually arrive within a few days rather than a few hours. Issues with a clear reproduction get fixed fastest.
